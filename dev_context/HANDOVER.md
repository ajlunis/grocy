# HANDOVER: Stock Overview Filtering Overhaul

**Starting Point:** Commit `de74b17ce264ce17b8d07e9d67967b6853bd74a8` (Merge pull request #41 from ajlunis/feature-tooltip-and-deep-linking).

## Project Goal
Implement a comprehensive, user-configurable filtering system on the Stock Overview page (`/stockoverview`).

## Requirements (Detailed)
1.  **Refactor Existing Filters:**
    *   **Location, Product Group, Status**: Convert from single `<select>` to **Multi-select** (using `bootstrap-select`).
    *   **Logic**:
        *   Selections within a filter are **OR** (e.g., Location A OR Location B).
        *   Logic between filters is **AND** (e.g., Group X AND Status Y).
        *   Default state: "All" selected.
    *   **"Not Set" Option**: All filters (except Location which is mandatory) must include a "Not Set" option to filter for null/empty values.

2.  **Dynamic "Add Filter" System:**
    *   The user should be able to dynamically add extra filters from a dropdown list.
    *   Added filters should have a "Remove" (Trash) button.
    *   "Clear Filter" button must reset everything: remove dynamic filters, reset permanent filters to "All".

3.  **New Filter Types & UI:**
    *   **Numeric (Amount, Min Stock, Calories, etc.):**
        *   Operators: `=`, `<`, `>`.
        *   Input: Number field.
        *   **Requirement:** +/- buttons to increment/decrement the value.
    *   **Currency (Value, Last Price, etc.):**
        *   Same as Numeric but with currency symbol formatting.
    *   **Date (Last Purchased):**
        *   Operators: `On`, `Before`, `After`.
        *   Input: Date picker (using `tempusdominus` or similar).
        *   **Presets:** "In the last week", "In the last month", "In the last year", "Over a year ago".
    *   **Userfields:**
        *   Must be dynamically generated based on the userfields defined for `products`.
        *   Located in the "Add Filter" dropdown under a separate group.
        *   **Mappings:**
            *   Checkbox -> Checked/Unchecked/Not Set.
            *   Date -> Date picker logic.
            *   Number/Currency -> Numeric logic.
            *   Link/File/Image -> Set/Not Set.
            *   Select/Master Data -> Multi-select.
            *   **Multi-select Userfields:** "Multi-select of a Multi-select". Must include a toggle for **AND/OR** logic between selected options, and an "Exact Match" checkbox if AND is selected.

## Known Bugs & Issues (To Fix)
1.  **UI "Wonkyness" / Double Dropdowns:**
    *   The interaction between Bootstrap 4's `.input-group`, `.custom-select`, and `bootstrap-select` is broken.
    *   Symptoms: Two dropdowns appearing (one native, one styled), or container-in-container layout issues causing elements to be hidden or misaligned.
    *   **Fix Needed:** proper cleanup of classes and robust initialization of `bootstrap-select` that respects the `input-group` layout.
2.  **Broken Functionality:**
    *   The filtering logic itself (DataTables search extension) works in theory but the UI controls are often not updating the state correctly or are inaccessible due to the UI bugs.
    *   "Not Set" logic needs rigorous testing across all types.
3.  **Missing Visual Polish:**
    *   +/- buttons on numeric filters need to be styled and positioned correctly within the input group.
    *   Date presets need to be easily accessible (currently implemented as a dropdown appended to the group).
